# USGS-Mineral-Yearbook

## Folder Structure
- `/data`
  - `/original_url`: URLs for USGS reports since 2005 by continent (retrieved in May 2026)
    - `/reports_new`: URLs for USGS reports since 1995 by continent (retrieved in mid-June 2026)
    - `/tables_new`: URLs for USGS annexed tables since 1995 by continent (retrieved in June 2026)
  - `/merged_url`: Concatenate all URLs to one table
  - `/original_report`: Downloaded PDF Reports since 2005 (retrieved in May 2026) (**NOT UPLOADED**)
  - `/policy_section_txt`: Plain text of "Government Policies and Programs" section extracted from PDF Reports (**NOT UPLOADED**)
  - `/text_parsing_json`: JSON-schema output from LLMs as output for coding text data (**NOT UPLOADED**)
- `/log`: Worklog generated by batch processing notebooks
- `/modules`: Encapsulated modules (in .py)
- `/notebooks`: Pipelines with notes for individual tasks (in .ipynb)
  - `/retrieve_url`: Retrieve URLs for USGS reports since 2005 by continent (coded in May 2026). Outputs are saved to `/data/original_url`.
  - `/retrieve_url_tables`: Retrieve URLs for USGS reports and annexed tables since 1995 by continent (coded in mid-June 2026). Outputs are saved to `/data/original_url/reports_new` and `/data/original_url/tables_new`.
  - `/download_files`: Batch download PDF Reports from retrieved URLs (coded in early June 2026). Outputs are saved to `/data/original_report`.
  - `/extract_text`: Extract plain text in "Government Policies and Programs" section from PDF Reports (coded from early to mid-June 2026). Outputs are saved to `/data/policy_section_txt`.
  - `/text_parsing`: Invoke LLM API for coding unstructured text data (coded in mid-June 2026). Outputs are saved to `/data/text_parsing_json`.
- `.gitignore`: Directories not uploaded to online repository
